# Gentone.ai (Type A/B) 레퍼런스 레이아웃 및 추가 기능 분석

본 문서는 로그인 후 접근 가능한 Gentone.ai의 생성 워크스페이스 구조 및 주요 추가 기능에 대한 분석 리포트입니다. 향후 A.BLUE 플랫폼의 AI 생성 스튜디오(Curation 등) 기획 및 개발에 참고 목적으로 작성되었습니다.

## 1. 핵심 레이아웃 구조 (2단 → 3단 구성 확장)

로그인 이전 단순 썸네일/뷰어 형태였던 레이아웃이, 로그인 후에는 본격적인 AI 생성 스튜디오 형태로 **3단 구조**로 변경됩니다.

- **좌측 (Selection Area):** 카테고리(상의/하의/원피스 등) 및 모델의 베이스 포즈를 선택하는 내비게이션 및 옵션 패널 영역입니다.
- **중앙 (Workflow & Prompt Area) [핵심]:** 
  - 선택한 의상과 아이템들이 중첩(Stacking)되어 하나의 '착장 세트'로 시각화되는 공간입니다.
  - 디테일한 텍스트 프롬프트를 입력할 수 있는 텍스트 에어리어가 존재합니다.
  - 최대 11장의 '레퍼런스 이미지'를 업로드할 수 있는 패널이 포함되어 있습니다.
- **우측 (Preview & Output Area):** 
  - 가장 넓은 영역을 차지하는 대형 워크스페이스 캔버스로, 모델 이미지가 크게 렌더링됩니다.
  - 하단에 해상도 설정(1K, 2K, 4K)과 '생성하기(Credit 소모)' 컨트롤러가 배치되어 있습니다.

## 2. 새로 활성화된 주요 생성 기능 타겟

### 2.1. 아이템 중첩 및 조합 (Overlay/Stacking)
- 사용자가 상의와 하의를 각각 선택하면 뷰가 전환되는 것이 아니라, 중앙 워크스페이스에 아이템들이 누적되며 하나의 코디네이션 세트가 형성됩니다.

### 2.2. 이미지 레퍼런스 확장 패널
- 텍스트만으로는 표현하기 힘든 구도, 분위기, 조명 등을 학습시키기 위해 다량의 레퍼런스 이미지(최대 11장)를 첨부할 수 있습니다. 생성 퀄리티를 보정하는 주요 수단입니다.

### 2.3. 후보정 커뮤니케이션 (Refinement)
- 1차 생성된 결과물에 대해 우측 상단 '후보정 리스트/모달'을 열어 추가 코멘트(최대 3개)를 작성할 수 있습니다. (예: "머리색을 조금 더 밝게", "재킷 기장을 짧게")
- 코멘트 기반으로 모델이 결과물을 디테일하게 리터칭합니다.

### 2.4. 영상 생성 모드 (Video Generation Link)
- 정지된 룩북 캔버스 상단에 위치한 **[▶ (Play)]** 아이콘 클릭 시, 현재 세팅된 이미지 결과물을 바탕으로 즉석에서 Video Generation 모드로 연동됩니다.

### 2.5. 디테일 부분 마스킹 툴 (Type B 전용)
- 브러시(Brush), 매직 완드(Magic Wand) 등 에디터 도구가 상단 툴바에 노출되어, 착장을 입힐 부위를 AI에게 텍스트가 아닌 물리적 영역으로 정밀하게 지시할 수 있습니다.

## 3. A.BLUE 프로젝트 적용 방안 제언

현재 A.BLUE-FE의 `QuickViewModal`은 우측 메인 이미지, 좌측 스타일 정보로 나뉜 '2단 분할 뷰어'의 성격을 띠고 있습니다. 만약 유저가 직접 룩북을 생성/오케스트레이션하는 경험을 설계해야 한다면:

1. **QuickViewModal 내 모드 전환:** 뷰어 모드에서 '에디트(생성) 모드'로 전환 시 좌측에 스택/프롬프트 영역(새로운 중앙 패널)이 슬라이딩되어 노출되도록 3단 레이아웃을 구성할 수 있습니다.
2. **독립 Curation Canvas 페이지 활용:** 이미 `/hq/curation` 형태의 Curation Canvas 페이지가 있다면, 해당 캔버스에서 위 3단 레이아웃을 그대로 차용하여 좌측 30%(아이템/프롬프트) + 우측 70%(대형 캔버스 및 컨트롤) 비율로 구현하는 것이 이상적입니다.
