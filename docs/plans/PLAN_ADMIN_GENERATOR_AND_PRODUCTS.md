# PLAN: AI Generator & Product Management (Admin 고도화)

## 1. 개요 (Overview)
기존의 `Curation Dashboard`가 이미 만들어진 결과를 '검수'하는 곳이라면, 본 기획은 관리자가 능동적으로 **AI 룩북을 창작(AI Generative Workspace)**하고, 그 뼈대가 되는 **카페24 상품 데이터를 관리(Product Management)**하는 핵심 기능을 설계합니다.

---

## 2. 파트 1: AI 룩북 수동 생성 캔버스 (Generative Workspace)
**경로**: `/admin/generator` (또는 `/admin/create`)
**목표**: 특정 기획전(예: 봄/여름 시즌 세일), 신상품 프로모션 등을 위해 관리자가 직접 프롬프트와 상품을 엮어 즉각적으로 룩북을 생성.

### 2.1. UI/UX 레이아웃 (좌승우반 패턴 유지)
어드민 UI의 일관성을 위해 큐레이션 화면과 동일한 `좌측 컨트롤 + 우측 프리뷰` 패러다임을 따릅니다.

- **좌측 제어 패널 (Control Sidebar)**
  - **Prompt Input (무드 설정)**: 시크한, 해변 배경, 스튜디오 조명 등 생성할 AI 이미지의 텍스트 지시어 입력창.
  - **레퍼런스 이미지 업로드**: 젠톤(Gentone) UI처럼 뼈대가 될 포즈나 스타일 참고용 구상 이미지를 첨부(Drag & Drop).
  - **상품 매핑 (Product Mapper)**: 룩북 하단에 연동될 **카페24 아이템(예: 데님 팬츠, 시그니처 자켓)**을 검색하여 최소 1~3개 연결하는 드롭다운/태그 인풋.
  - **해상도 및 비율 선택기**: `1:1`, `3:4`, `9:16` 등 세그먼트 버튼 적용.
  - **[✨ GENERATE] 액션 버튼**: 그라데이션 및 로딩 스피너 등의 트랜지션 적용.

- **우측 프리뷰 캔버스 (Preview Canvas)**
  - **생성 중 (Loading State)**: 프로그레스바 또는 스켈레톤 UI (Gemini API 응답 대기).
  - **결과 출력 (Result View)**: 생성된 고해상도 이미지가 중앙에 노출되며, 마음에 들 경우 즉각 갤러리에 발행하는 **[PUBLISH (APPROVED)]** 버튼 또는, 다시 생성하는 **[RE-GENERATE]** 버튼 제공.

## 3. 파트 2: 상품 동기화 및 관리 (Product Management)
**경로**: `/admin/products`
**목표**: 카페24에서 긁어온(API 연동) 상품 데이터를 리스트뷰로 확인하고, 룩북 생성의 '재료'로서 상태가 적합한지 1차 필터링.

### 3.1. UI/UX 레이아웃
이 페이지는 이미지가 아닌 **'데이터(재고, 가격, 판매상태)' 위주의 테이블형 구조**를 가집니다.

- **데이터 그리드(Table View)**
  - 컬럼: 썸네일 이미지, 상품ID, 상품명, 가격, **실시간 재고(Stock)**, 동기화 상태.
- **상위 컨트롤 바 (Filters & Actions)**
  - **동기화 트리거**: **[수동 동기화(Sync Now)]** 버튼을 두어 카페24와 강제 Sync 기능 제공.
  - **품절 스위치**: '품절된 상품 제외하고 보기' 토글. (품절 상품이 포함된 룩북은 노출되면 안 됨)
  - **노출 오버라이드 제어기**: 시스템 오류나 판매 중단 시 해당 상품을 띄우지 않도록 `HIDDEN` 처리할 수 있는 아이템별 스위치 기능.

---

## 4. 백엔드 연동 요구사항 (To-Do for Backend)

이 두 가지 화면을 구현하기 위해 백엔드에 다음과 같은 API가 추가로 요청됩니다. 문서를 백엔드 개발자분들께 전달해 주세요.

### 4.1. 수동 기능 (Generator) 연동
- **`[POST]` AI 수동 생성 API**: 
  - (Request): `prompt`(String), `referenceImageUrl`(String/File), `cafe24ProductIds`(Array)
  - (Response): `jobId`를 주고 웹소켓/폴링으로 대기시키거나, 비동기 완료 시 `imageUrl`과 생성된 `Lookbook Entity` 객체 즉시 반환.

### 4.2. 상품 관리 (Products) 연동
- **`[GET]` 카페24 연동 데이터 리스트 API**: 
  - 페이징 처리가 된 상품 리스트 (재고 수량 포함 필수).
- **`[POST]` 상품 수동 동기화 (Webhook/Sync) API**: 
  - 어드민에서 버튼 클릭 즉시, 카페24와 강제로 재고 및 상품 상태를 맞추는 통신.
- **`[PATCH]` 상품 상태 강제 변경 API**: 
  - 시스템 상 강제로 상품을 `HIDDEN` 시킬 때 사용.
